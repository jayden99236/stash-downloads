# Stash downloads

Installers for the **Stash** apps. Stash is a free read-later app: save links, get short AI summaries, and keep notes and tasks in one place. It runs at **https://stashlinked.vercel.app**. The easiest way to download is the site's **[Download page](https://stashlinked.vercel.app/download)**.

This repository contains only the app files; the source code is private.

| App | Where |
|---|---|
| Android | `stash-<version>.apk` in the latest **mobile** release |
| Windows | `Stash-<version>-win-x64.exe` in the latest **desktop** release |
| macOS | `Stash-<version>-mac-universal.dmg` |
| Linux | `.AppImage` or `.deb` |

The apps are free and aren't signed by Apple or Microsoft yet, so:

- **Android:** allow "Install unknown apps" for your browser when asked.
- **Windows:** if SmartScreen appears, click *More info → Run anyway*.
- **macOS:** open the app with right-click → *Open*. If macOS says it's damaged, run `xattr -dr com.apple.quarantine /Applications/Stash.app`.
